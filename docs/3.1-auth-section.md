# 3.1 — Sekcja: `authentication`

## Źródło

- `routers/authentication/auth.py`, `schemas.py`, `utilities.py`
- `JWT/authenticationRouter.py`, `JWT/jwt_helper.py`

## Endpointy obecne

| Metoda | Path | Auth | Uwaga |
|---|---|---|---|
| POST | `/authentication/login` | brak | zwraca prawdziwy JWT tylko dla `type == "administrator"`, inni dostają losowy `secrets.token_hex(220)` jako "token" |
| POST | `/authentication/automaticallyLogin` | refresh token w body | odświeżenie access tokena |

## Problemy do naprawienia przy migracji

- [ ] Jeden spójny mechanizm JWT dla wszystkich ról (nie tylko admina)
- [ ] Rewokacja tokenów (obecnie brak — token raz wydany żyje do wygaśnięcia)
- [ ] `jwt.decode(token, secret, config("ALGORITHM"))` — pozycyjny argument
      algorytmu zamiast `algorithms=[...]`, do zweryfikowania pod aktualną
      wersję PyJWT
- [ ] Sesja DB w `auth.py`: `db = SessionLocal()` global — przenieść na
      `Depends(get_db)`
- [ ] Hasła: `passlib[bcrypt]` zostaje czy przechodzimy na gołe `bcrypt`
      (zgodnie z `core/common/bcrypt_password.py` z wzorca)?
